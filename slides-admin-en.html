🛡️ Admin Role

Difference from Regular Users

  • Edit & delete any team member's record
  • Approve / reject sign-up requests
  • View & delete approved users
  • Promote users to admin
  • Use the Excel Export Code
  • 🛡️ Access the Approval tab

How to Get Admin Access

  • Sign up normally, then ask an existing admin to promote you
  • 🛡️ Approval tab → "✅ Approved Accounts" → "⬆ Promote to Admin"
  • The 🛡️ tab appears immediately after promotion

Admin Login

1
Unlock the App with Access Code
Enter the team's shared Access Code, same as regular users.
2
Log in with your Admin account
Enter your admin User ID and password. On success, the 🛡️ Approval tab appears in the bottom navigation.
3
Confirm the Admin Tab
Regular users do not see the 🛡️ tab. If it's missing, admin privileges are not active or you're not logged in.
⚠️ Password Warning — There is no password reset feature. Write down your admin password and keep it safe.

🛡️ Processing Sign-up Requests

🛡️ Approval tab → top section "⏳ Pending Requests"

1
Review the request list
Pending requests appear as cards showing the requester's name, User ID, and request time.
2
✓ Approve / ✗ Reject
Approving activates the account immediately. Rejection allows an optional reason. Duplicate User IDs are automatically rejected.
3
User can log in after approval
Approved users can log in right away. There's no automatic notification, so inform them via KakaoTalk or similar.

👥 Managing Approved Users

🛡️ Approval tab → bottom section "✅ Approved Accounts"

View User List
All approved DB accounts are listed with name, User ID, role (USER/ADMIN), and join date.
⬆ Promote to Admin PROMOTE
Tap "⬆ Promote to Admin" next to a USER account to grant ADMIN privileges. The 🛡️ tab appears for that user immediately.
🗑 Delete Account DELETE
Deleted accounts are locked out immediately. You cannot delete your own account. Records saved by the user remain in the DB.

🔒 Record Lock Rules

Records with all 6 fields filled are auto-locked after saving.

🔒 Lock Conditions (all 6 required)

Date Date Display Time Start Time End Manage No. Process
How to edit a locked record?
Tap "Unlock / 잠금 해제" on the record card and enter the Unlock Code. Contact the app operator for the code.
Admins can unlock any record
Regular users can only unlock their own records; admins can unlock any record with the Unlock Code.

📊 Excel Export

📋 All Records tab → "Export / 내보내기" button at the bottom

1
Enter Export Code
Tapping the export button prompts for an Export Code. Contact the app operator for the code.
2
Choose Export Type
📊 Full Excel — Download all saved records
🆕 New Excel — Only records added since the last export
3
Photos included automatically
Evidence photos attached to records are embedded in the Excel file at full quality.

⚠️ Password Management

This app has no password recovery or reset feature.

It is an intentionally simple logging tool — no email verification or SMS authentication.
A user forgot their password?
Delete the user's account and ask them to sign up again with a new ID. Their previously saved records remain in the DB.
You forgot your own admin password?
Ask another admin to delete your account and re-create it via sign-up + promote, or contact the app operator.
Remind your team
Ask everyone to write down or remember their password from day one.
