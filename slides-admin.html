🛡️ 관리자(Admin) 역할

일반 유저와 차이점

  • 모든 팀원의 기록 수정·삭제 가능
  • 가입 요청 승인 / 거절
  • 승인된 유저 목록 조회 & 삭제
  • 일반 유저를 관리자로 승격
  • 엑셀 Export Code 사용 가능
  • 🛡️ 승인/Approval 탭 접근

관리자 계정 얻는 방법

  • 일반 가입 후 기존 관리자에게 승격 요청
  • 🛡️ 승인 탭 → 「✅ 승인된 계정」에서 관리자가 「⬆ 관리자 승격」 처리
  • 승격 직후 🛡️ 탭이 나타납니다

관리자 로그인

1
Access Code로 앱 잠금 해제
일반 유저와 동일하게 팀 공용 Access Code를 입력합니다.
2
관리자 계정으로 로그인
관리자 User ID와 비밀번호로 로그인합니다. 로그인 성공 시 하단 탭에 🛡️ 승인/Approval 탭이 나타납니다.
3
관리자 탭 확인
일반 유저에게는 🛡️ 탭이 보이지 않습니다. 탭이 안 보이면 관리자 권한이 없거나 로그인이 안 된 상태입니다.
⚠️ 비밀번호 경고 — 이 앱은 비밀번호 찾기 기능이 없습니다. 관리자 계정 비밀번호는 반드시 메모해두세요.

🛡️ 가입 요청 처리

하단 탭 「🛡️ 승인/Approval」 → 상단 섹션 「⏳ 승인 요청」

1
요청 목록 확인
대기 중인 가입 요청이 카드 형태로 나열됩니다. 요청자 이름, User ID, 요청 시간이 표시됩니다.
2
✓ 승인 / ✗ 거절
승인하면 즉시 해당 계정이 활성화됩니다. 거절 시 사유를 입력할 수 있습니다. 중복 User ID가 있으면 승인이 자동 거절됩니다.
3
승인 후 로그인 가능
승인된 유저는 즉시 로그인할 수 있습니다. 별도 알림은 없으므로 카카오톡 등으로 안내하세요.

👥 승인된 유저 관리

🛡️ 승인/Approval 탭 → 하단 섹션 「✅ 승인된 계정」

유저 목록 조회
승인된 모든 DB 계정이 표시됩니다. 이름, User ID, 역할(USER/ADMIN), 가입일을 확인할 수 있습니다.
⬆ 관리자로 승격 PROMOTE
일반 유저(USER) 옆의 「⬆ 관리자 승격」 버튼을 누르면 ADMIN 권한이 부여됩니다. 승격 후 해당 유저에게 🛡️ 탭이 나타납니다.
🗑 계정 삭제 DELETE
삭제된 계정은 즉시 로그인 불가가 됩니다. 본인 계정은 삭제할 수 없습니다. 저장된 기록은 DB에 유지됩니다.

🔒 기록 잠금 기준

아래 6가지 항목이 모두 입력된 기록은 저장 후 자동으로 잠깁니다.

🔒 잠금 조건 (6가지 전부 필요)

날짜 (Date) 날짜 표시 (Date Display) 시작 시간 (Time Start) 종료 시간 (Time End) 관리번호 (Manage No.) 공정명 (Process)
잠긴 기록 수정하려면?
기록 카드의 「잠금 해제 / Unlock」 버튼을 누르고 Unlock Code를 입력합니다. 코드는 앱 운영자에게 문의하세요.
관리자는 모든 잠긴 기록 수정 가능
일반 유저는 본인 기록만, 관리자는 모든 기록에 Unlock Code로 수정 권한을 얻을 수 있습니다.

📊 엑셀 내보내기

「📋 전체 기록」 탭 → 하단 「내보내기 / Export」 버튼

1
Export Code 입력
내보내기 버튼을 누르면 Export Code 입력창이 뜹니다. 코드는 앱 운영자에게 문의하세요.
2
내보내기 유형 선택
📊 전체 Excel — 저장된 전체 기록 엑셀 다운로드
🆕 신규 Excel — 마지막 내보내기 이후 추가된 기록만
3
사진 포함 자동 처리
증거 사진이 첨부된 기록은 엑셀 파일에 이미지가 자동으로 삽입됩니다. 화질 저하 없이 원본 그대로 저장됩니다.

⚠️ 비밀번호 관리 주의

이 앱에는 비밀번호 찾기 / 재설정 기능이 없습니다.

단순 기록용 앱이기 때문에 이메일 인증, SMS 인증 등의 복잡한 기능을 의도적으로 구현하지 않았습니다.
DB 유저 비밀번호를 잊었다면?
해당 유저의 계정을 삭제하고, 유저가 새 ID로 다시 가입 요청하도록 안내합니다. 기존에 저장한 기록은 그대로 유지됩니다.
팀원에게 안내하세요
유저 가이드에도 동일 내용이 있습니다. 비밀번호는 메모해두거나 기억하기 쉬운 것을 사용하도록 안내하세요.
