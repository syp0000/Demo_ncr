NCR Assistant · Floating Count · User Guide

What is this app?

A web app to quickly log floating count events in a structured format during process work, visible to the whole team from a shared database.

Key Features

  • 📝 Structured input form
  • ✨ AI text polish (KO / EN)
  • 👁 Live preview & copy
  • 💾 Shared DB save & view
  • 📸 Evidence photo attachment

Tab Layout

  • ✏️ Input — Write a report
  • 📋 My Records — Your saved entries
  • 📋 All Records — Full team records
  • 👤 My Info — Account & logout

Step 0 · Accessing the App

1
Open the shared link
Open the Vercel URL in your browser. On first visit you'll see the SECURE ACCESS lock screen.
2
Enter the Access Code
Enter the team Access Code and tap "Unlock App" or press Enter. Future visits are remembered automatically.
3
Personal Login
Log in with your User ID and password. Session stays active for 30 days.
No account yet? Tap "Sign Up Request →" at the bottom of the login screen.

Requesting an Account

1
Tap "Sign Up Request →"
The link at the bottom of the login screen opens the registration form.
2
Fill in your details
Enter a User ID (lowercase letters/numbers, 3–40 chars), your name, and a password, then tap "Send Request".
3
Wait for admin approval
Once approved, log in with your ID and password. Login is not possible before approval.
⚠️ Remember your password!
There is no password reset feature. If forgotten, you must sign up again with a new ID.
Use a memorable password or write it down.

Step 1 · Basic Information

✏️ Input tab → top card

①
Date & Night Shift
Pick the work date from the date picker. Tap the "Night" chip to mark a night shift.
②
Time (Start / End)
Enter start and end times in HH:MM format. Duration is calculated automatically.
③
Management No.
Use +/− buttons or type directly. Tap the bracket chip to append a suffix if needed.
④
Process
Select from the dropdown. If not listed, choose "Other (manual)" and type the name.

Step 2 · Content & AI Polish

①
Remarks
Briefly describe the issue or inspection finding.
②
Follow-up Actions
Describe the corrective actions taken.
③
📸 Evidence Photo Optional
Attach a photo from camera or gallery. Included automatically in Excel export.
④
✨ AI Polish Optional
Choose "Korean" or "English", then tap "✨ Polish". Review the AI-corrected text and tap ✓ Apply or cancel.

Step 3 · Save & Record Lock

①
📋 Copy
Copies the preview text to clipboard. Paste directly into KakaoTalk or any messaging app.
②
✅ Save Record
Saves to the shared database. Immediately visible to all team members under "All Records".

🔒 When Does a Record Lock?

A record locks automatically when all 6 fields are filled:

Date Date Display Time Start Time End Manage No. Process

To edit a locked record, an Unlock Code is required. Contact your admin.

Step 4 · Viewing Records

📋 My Records

  • Shows only your own records
  • Default: newest first
  • Search & status filter (All/Open/Done)
  • Edit your own records

📋 All Records

  • Shows all team members' records
  • Author name displayed
  • Other members' records: view only
  • Admins can edit all records
Deleted records go to Trash
Deleted records are not permanently removed immediately — they move to the Trash. Use the "Trash" button to review or restore them.

👤 My Info Tab

User ID
Your current login ID. This cannot be changed.
Change Display Name
Edit your name and tap "Save" to update it.
Logout
Tap "↩ Logout" to sign out. Always log out after using a shared device.
⚠️ Never forget your password
There is no password reset feature.
If forgotten, you must sign up with a new ID and request admin approval again.

Install as an App (PWA)

Add to home screen to use like a native app — no address bar.

iPhone / iPad
  1. Open the link in Safari
  2. Tap the Share button (□↑)
  3. Select "Add to Home Screen"
  4. Tap "Add"
⚠️ Safari only — Chrome does not support this on iOS.
🤖 Android
  1. Open the link in Chrome
  2. Tap ⋮ in the top-right corner
  3. Select "Add to Home Screen" or "Install App"
  4. Tap "Add" to confirm
💡 If an install banner appears automatically, just tap "Install".

Frequently Asked Questions

Q. I forgot my password.
There is no reset option. Sign up again with a new ID and ask your admin for approval.
Q. I can't find my records.
Try searching or changing the sort order in the "My Records" tab. Records are shown newest-first by default.
Q. My record is locked and I can't edit it.
Records with all 6 fields filled are auto-locked. To edit, ask your admin for the Unlock Code.
Q. AI Polish isn't working.
Check your internet connection. The feature won't run if the text fields are empty.
