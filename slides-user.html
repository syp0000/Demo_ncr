NCR Assistant · 공정 부동집계 · 유저 가이드

이 앱은 무엇인가요?

공정 작업 중 발생한 부동 내용을 구조화된 형태로 빠르게 기록하고, 팀원 전체가 공유 DB에서 조회할 수 있는 웹 앱입니다.

핵심 기능

  • 📝 구조화된 입력 폼
  • ✨ AI 텍스트 다듬기 (한/영)
  • 👁 실시간 미리보기 & 복사
  • 💾 공유 DB 저장 & 조회
  • 📸 증거 사진 첨부

탭 구성

  • ✏️ 입력/Input — 보고서 작성
  • 📋 내 기록 — 내가 저장한 기록
  • 📋 전체 기록 — 팀원 전체 기록
  • 👤 내 정보 — 계정 정보 & 로그아웃

Step 0 · 앱 접속

1
공유받은 링크 열기
Vercel URL을 브라우저에서 엽니다. 처음 접속 시 잠금 화면 (SECURE ACCESS)이 표시됩니다.
2
Access Code 입력
팀에서 공유하는 앱 공용 코드를 입력 후 「Unlock App」 또는 Enter를 누릅니다. 다음 접속부터는 자동 인증됩니다.
3
개인 로그인
User ID와 비밀번호로 로그인합니다. 30일간 자동 로그인이 유지됩니다.
아직 계정이 없다면? 로그인 화면 하단 「회원가입 요청 →」을 탭하세요.

회원가입 요청하기

1
「회원가입 요청 →」 탭
로그인 화면 하단 링크를 탭하면 가입 요청 폼이 열립니다.
2
정보 입력
User ID (영문 소문자/숫자, 3~40자), 이름, 비밀번호를 입력하고 「가입 요청 보내기」를 탭합니다.
3
관리자 승인 대기
관리자가 승인하면 입력한 ID와 비밀번호로 로그인할 수 있습니다. 승인 전에는 로그인이 불가합니다.
⚠️ 비밀번호를 꼭 기억하세요!
비밀번호 찾기 기능이 없습니다. 잊어버리면 새 ID로 다시 가입 요청하는 방법밖에 없습니다.
메모해두거나 기억하기 쉬운 비밀번호를 사용하세요.

Step 1 · 기본 정보 입력

「✏️ 입력/Input」 탭 → 상단 카드

①
일시 / Date & 야간 여부
날짜 선택기에서 작업 날짜를 고릅니다. 야간이면 「야간」 칩을 탭해 활성화합니다.
②
시간 / Time
시작 시간과 종료 시간을 HH:MM 형식으로 입력하면 소요 시간이 자동 계산됩니다.
③
관리번호 / Management No.
＋/− 버튼으로 조정하거나 직접 입력. 접미어가 필요하면 괄호 칩을 탭 후 문자를 추가합니다.
④
공정명 / Process
드롭다운에서 선택. 목록에 없으면 「기타 (직접입력)」 선택 후 직접 입력합니다.

Step 2 · 작업 내용 & AI 다듬기

①
특이사항 / Remarks
발생한 이슈나 점검 결과를 간략히 적습니다.
②
조치사항 / Follow-up Actions
조치한 내용을 적습니다.
③
📸 증거 사진 선택
카메라 촬영 또는 갤러리에서 사진을 첨부할 수 있습니다. 첨부 시 엑셀 내보내기에도 포함됩니다.
④
✨ AI 다듬기 선택
「한국어」 또는 「English」를 선택 후 「✨ 다듬기」 버튼을 누릅니다. AI가 교정한 문장을 확인하고 ✓ 적용 또는 취소를 선택합니다.

Step 3 · 저장 & 기록 잠금

①
📋 복사 / Copy
미리보기 텍스트를 클립보드에 복사합니다. 카카오톡 등에 바로 붙여넣기 가능합니다.
②
✅ 기록 저장 / Save Record
공유 DB에 저장합니다. 저장 후 팀원 모두가 「전체 기록」 탭에서 조회할 수 있습니다.

🔒 기록이 잠기는 조건

아래 6가지 항목이 모두 입력된 기록은 저장 후 자동으로 잠깁니다.

날짜 (Date) 날짜 표시 (Date Display) 시작 시간 종료 시간 관리번호 공정명

잠긴 기록은 수정하려면 Unlock Code가 필요합니다. (관리자에게 문의)

Step 4 · 기록 조회

📋 내 기록 탭

  • 내가 저장한 기록만 표시
  • 기본: 최근 기록 최신순
  • 검색 · 상태 필터 (All/Open/Done)
  • 직접 저장한 기록 수정 가능

📋 전체 기록 탭

  • 팀원 모두의 기록 표시
  • 작성자 이름 표시
  • 타인 기록은 조회만 가능
  • 관리자는 모든 기록 수정 가능
기록 삭제는 휴지통으로
삭제한 기록은 바로 사라지지 않고 휴지통으로 이동합니다. 「휴지통/Trash」 버튼으로 확인 & 복구할 수 있습니다.

👤 내 정보 탭

User ID
로그인 중인 계정 ID입니다. 변경할 수 없습니다.
이름 변경
표시 이름을 수정하고 「저장」을 눌러 업데이트할 수 있습니다.
로그아웃
「↩ 로그아웃」 버튼으로 로그아웃합니다. 다른 기기에서 사용 후 꼭 로그아웃하세요.
⚠️ 비밀번호를 절대 잊지 마세요
비밀번호 찾기·재설정 기능이 없습니다.
잊어버리면 새 ID로 가입 요청하고 관리자에게 재승인을 받아야 합니다.

앱처럼 사용하기 (PWA)

홈 화면에 추가하면 주소창 없이 앱처럼 실행됩니다.

iPhone / iPad
  1. Safari에서 링크 열기
  2. 하단 공유 버튼 (□↑) 탭
  3. 「홈 화면에 추가」 선택
  4. 「추가」 탭
⚠️ 반드시 Safari 사용. Chrome 불가.
🤖 Android
  1. Chrome에서 링크 열기
  2. 우측 상단 ⋮ 메뉴 탭
  3. 「홈 화면에 추가」 또는 「앱 설치」
  4. 「추가」 확인
💡 설치 배너가 자동으로 뜨면 바로 「설치」 탭.

자주 묻는 질문

Q. 비밀번호를 잊었어요.
재설정 기능이 없습니다. 새 ID로 다시 가입 요청하고 관리자에게 승인을 요청하세요.
Q. 내 기록이 안 보여요.
「내 기록」 탭에서 검색하거나 정렬 순서를 변경해보세요. 최근 기록 위주로 표시됩니다.
Q. 기록이 잠겨서 수정이 안 돼요.
날짜·시간·관리번호·공정명이 모두 입력된 기록은 자동 잠금됩니다. 수정이 필요하면 관리자에게 Unlock Code를 요청하세요.
Q. AI 다듬기가 작동 안 해요.
인터넷 연결 상태를 확인하세요. 텍스트 필드가 비어있으면 실행되지 않습니다.
